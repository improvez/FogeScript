# FogeScript

Aqui está o dicionário completo da linguagem SenhoraC em formato de texto limpo e organizado por tópicos, totalmente livre de conflitos e duplicatas:

Dicionário Oficial da Linguagem SenhoraC


Início (main): A SENHORA TRABALHA NA ASSEMBLEIA?

Significado: Ponto de entrada do programa.

Saída (print): TEMOS GRAVADO!

Significado: Exibe dados na tela (a prova irrefutável).

Entrada (input): QUER CONVERSAR COMIGO?

Significado: Lê dados digitados pelo usuário.

Declaração de Variável (var): A SENHORA FEZ

Significado: Declara e atribui uma variável.

Condicional (if): SE A SENHORA NÃO É FUNCIONÁRIA

Significado: Executa o bloco se a condição for verdadeira.

Condicional Alternativa (else): E TÁ CORRENDO POR QUÊ?

Significado: Executa caso a condição do if falhe.

Laço de Repetição (while): ENQUANTO TIVER CORRENDO

Significado: Repete o bloco enquanto a condição for ativa.

Laço Contado (for): SENHORA? SENHORA?!

Significado: Loop de repetição com limite de chamadas.

Tentativa (try): DEIXA EU TE PERGUNTAR

Significado: Tenta executar um bloco arriscado de código.

Interrupção (break): VOLTA AQUI!

Significado: Interrompe o laço de repetição imediatamente.

Pular Iteração (continue): DEIXA ELA CORRER

Significado: Pula a iteração atual do loop e vai para a próxima.

Declaração de Função (function): NÃO, EU NUNCA FIZ ISSO

Significado: Define um bloco reutilizável (o álibi).

Chamada de Função (call): CHAMA A SENHORA

Significado: Invoca a execução de uma função previamente declarada.

Retorno (return): CHEGA DE CORRER

Significado: Retorna um valor de uma função.

Verdadeiro (true): VERDADEIRAMENTE GRAVADO

Significado: Valor booleano verdadeiro.

Falso (false): NUNCA FIZ ISSO

Significado: Valor booleano falso.
